# H3 制作与核验

用于用户明确指定 MiniMax H3 或已接好的 ComfyUI 服务。以运行中的节点接口和模型为准。可同时参考已安装的 h3-short-drama、h3-gpt-image-mv 技能。节点和工作流见 [ComfyUI 官方 H3 文档](https://docs.comfy.org/tutorials/video/minimax/minimax-h3-native)。

- 有确定构图就用 I2V 首帧，描述从这张图出发会发生的一个动作。涉及多角色参考、特定音色或表演时，再按服务能力选 R2V 或音频引导。参考图按镜头画幅准备，必要时先裁切或留边，避免节点拉伸角色。
- 先跑最难的一镜，记录分辨率、原始帧数、种子和实际耗时。根据节点允许的帧数网格选取能覆盖剪辑长度的档位。服务地址使用用户给的值，8188 是一个常见端口。生成尺寸、模型精度、推理步数和故事片长按项目决定。
- 用户要 H3 原声时，将音频解码输出接到封装节点，下载含音轨的原始 MP4。逐镜核对台词、发音、音轨末尾与口型。场景需要同一声音由远到近时，可用同一段 H3 音频分别处理远处和近处的版本。有与请求无关的可辨对白时，另选干净片段、用同源房间底声补缺口或重生成，并留下原始镜头。
- 批量提交时记录每镜的输入图、提示词、种子、实际工作流、任务号与下载结果。断线后查队列和历史后再决定是否重试，避免重复任务。单卡可串行运行，确认一个镜头完成并下载后继续。首帧或提示词修订使用新版本。
- 合片后检查分辨率、帧率、帧数、音轨、字幕和关键转场，并完整解码。输出分辨率高于源片时如实注明放大处理。剪辑、混音、分镜和有权使用的参考图可留作复用。
