# 小说短剧制作模板

按所需阶段选用以下表格。制作时用同一镜号关联首帧、视频、音轨与剪辑时间。

## 片段卡

- 原著与出处（作者、章节、起止位置）
- 观众需要知道的前情（一句能放入画面或对白的信息）
- 主角此刻的目标
- 迫使主角改变行动的一件事
- 原著里要保留的动作、物件、台词
- 压缩、重排或新增的内容
- 结尾的画面或声音，以及它留下的情绪
- 风格、目标片长、画幅、对白语言、声音来源

挑灵异戏时可以先验证三个画面。谁先察觉异常？异常如何改变人物的行动？最后观众看见或听见什么？例如一桌人突然停筷，两个孩子从侧门撤到后厨，远处的笑随后在头顶响起。

## 人物与场景卡

| 对象 | 持续复用的细节 | 可随镜头变化的细节 |
| --- | --- | --- |
| 人物 | 年龄感、面形、眉眼、发型、衣服、代表道具 | 表情、姿势、受光、镜头距离 |
| 道具 | 轮廓、材质、大小、叙事作用 | 谁拿着、落在哪里、使用前后状态 |
| 场景 | 出入口、遮挡、地形、主要光源、进出画方向 | 镜位、景别、灯光强弱和空间声 |

角色统一以后，用成片角度看辨识度。比如在纸人宴里，纸人的圆形腮红与活人的自然肤色共同提供身份线索。修订活人的脸之后，复查近景与有色环境光中的效果。

## 分镜卡

一镜可用以下字段表示。

| 字段 | 示例 |
| --- | --- |
| 镜号、时长 | 05，约 4.6 秒 |
| 叙事变化 | 孩子躲住，门口传来笑声 |
| 首帧与参考 | 机位在低处，砖灶挡住左下两人，门在画面右后方 |
| 主动作与落点 | 男孩压住同伴袖口，两人的视线停在门口 |
| 画面连续性 | 两人的服装、位置、脸部识别特征与上一镜一致 |
| 声音 | 笑声落在右后方，留出停顿，下一镜同一声源逼近 |
| 制作信息 | 输入图、模式、模型、种子或任务号、源帧范围、音轨和状态 |

片长以实际剪出的帧数为准。镜头制作清单可以直接用 CSV、JSON 或 Markdown；助记字段与交付对象一致即可。音频引导、末帧锁定、复杂多角色对白等控制应按当前工具支持情况使用。

## 常见返工点

- 惊吓来得早了，先检查首帧是否提前露出了答案。根据剪点重新安排看见的顺序。
- 角色在连续镜头里难认，检查机位、发型、肩线、服饰和色光。先修身份来源，再修受影响的镜头。
- 观众不知道角色为何换处境，找出前一镜缺失的动作或物证。必要时用一个短插入镜头补清因果。
- 对白开头或尾字听不全，核对原始音轨的真实起止，再定裁切与字幕时间。
